
JavaScript 是一门编程语言，在学习 JavaScript 之前，我们先来说说编程语言这个概念。

### 语言

语言，是沟通交流的表达方式。人与人之间用人类语言，机器与机器之间用机器语言(二进制 0/1)，那人与机器之间呢？

- 用机器语言？不可行，内容都是一堆 0 和 1，人类难以阅读和书写。
- 用人类语言？不可行，机器可不理解人类语言。
- 将人类语言翻译成机器语言呢？也不可行，因为机器语言需要明确的逻辑，人类语言的逻辑过于模糊，难以翻译。

既然各自的语言都不行，那就用一种逻辑明确的中间语言，这便是编程语言：它使用对人类友好的语法编写，然后使用编译器翻译成机器语言。

### 编程

编程，即编写程序，程序是解决问题的一套步骤，编写程序就是编写问题的解决方案。程序有 2 个核心的元素：

- 数据结构

数据是程序的基础，数据结构是组织数据的形式，为什么要关注数据结构呢？不同的数据结构，会影响到数据的查找速度和存储空间等。同样的数据，有的结构要 2M 内存，有的结构只要 1M 内存。

- 算法

算法是处理数据的一套步骤，不同的算法会影响执行速度和占用内存。同样的数据，有的算法排序要 2 分钟，有的算法排序只要 1 分钟，重要性不言而喻。

程序根据输入的数据结构，使用算法进行处理和修改，返回新的数据结构，其核心在于数据的流动。

### 编程语言

编程语言有很多分类，按贴近机器语言的程度，可分为：

- 低级语言：贴近机器思维，汇编语言是典型的低级语言，汇编语言本身没有数据类型，只有指令集，没有变量，只有内存。
- 高级语言：贴近人类思维，我们学习的大部分编程语言都是高级语言。

把大象放到冰箱里，用人类语言描述就是：

1. 打开冰箱
2. 把大象放进冰箱
3. 关闭冰箱

用编程语言描述(JS)就是：

```js
function putElephantInRefrigerator(elephant) {
  // 1. 打开冰箱
  openRefrigerator();
  // 2. 把大象放进冰箱
  putElephantInRefrigerator(elephant);
  // 3. 关闭冰箱
  closeRefrigerator();
}
```

用机器语言描述就是：

```
101011011011010.....
```

### 语言众多

就像人类有很多种语言一样，高级编程语言也有很多种，为什么编程语言有那么多呢？主要是侧重点不同，例如：

- 有的语言侧重性能和安全，例如：C、C++、Go、Rust。
- 有的语言侧重可读性，例如：Python、JavaScript、Ruby。
- 有的语言侧重可维护性，例如：Java、C#、Swift。
